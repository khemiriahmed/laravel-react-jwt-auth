Laravel React JWT Auth

A full-stack authentication application built with Laravel 12, React, Redux Toolkit, RTK Query, and PostgreSQL. It provides JWT-based authentication, protected routes, user profile management, and API documentation with Swagger.

Features
User registration and login
JWT authentication using Bearer tokens
Authenticated user profile (/api/me)
Token refresh and logout
Role support: USER and ADMIN
Protected frontend routes
Centralized API requests with RTK Query
Responsive user interface
REST API documentation with Swagger / OpenAPI
PostgreSQL database with Docker support
